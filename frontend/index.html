Features

Everything a department needs, nothing it doesn't.

Instant search

Find any student by ID, roll number, name, department or section in constant time via hash-indexed lookups.

One-tap attendance

Teachers mark a whole class present, absent, late, or on leave in seconds, with instant undo.

Live analytics

Trend lines, department comparisons, and leaderboards render straight from in-memory data structures.

Role-based security

JWT authentication and SHA-256 password hashing keep admin, teacher, and student data properly separated.

Exportable reports

Download attendance history and eligibility reports for any student, class, or subject.

Zero database

Everything runs on HashMap, HashSet, Stack, Queue and PriorityQueue — a live demonstration of DSA in production.

How it works

From roll call to report in four steps.

Sign in

Admins, teachers, and students each get a dedicated, secured dashboard.

Mark attendance

Teachers select a class, subject, and date, then tag each student's status.

Data indexes instantly

Every record hashes into memory for O(1) average lookups and updates.

Everyone sees results

Percentages, trends, and alerts update live across every dashboard.
